# Self-driving Car Simulation

A browser-based driving simulation built with plain JavaScript and the Canvas API.

## Project goal

Explore the foundations of autonomous-driving simulations by modeling a car, road geometry, controls and distance sensors without external libraries.

## Features

- Canvas-rendered road and vehicle
- Keyboard and automated controls
- Ray-based proximity sensors
- Collision-oriented geometry utilities

## Technologies

- **JavaScript**
- **HTML Canvas**
- **HTML**
- **CSS**

## What I learned

- Modeling movement and steering with basic geometry
- Drawing an animated world on Canvas
- Casting sensor rays and detecting intersections
- Separating simulation responsibilities into small classes

## Running locally

Open `index.html` in a browser.

## Project status

This is a learning and experimentation repository. It documents the concepts practiced at the time and is not presented as a production-ready application.
